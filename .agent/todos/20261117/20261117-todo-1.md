Wave 8 supersedes the zip-only distribution with an **executable wizard installer** and adds **GitHub Releases** publishing, plus three UX deliverables: README TOC/long-doc indexes, a consolidated hotkeys record, and the window-title path feature. The user's 2026-11-17 request (binding): "The only thing you did was to generate zip files to be extracted. However, I'm looking for an executable wizard installer.
