- [x] Wave 2 — Horizontal scroll (sibling images, current folder, alphanumeric order).
- [x] Wave 3 — Vertical scroll (sibling folders under the SAME parent; NO same-filename rule — removed per user decision 2026-10-29; the target image is ALWAYS the target folder's first image in alphanumeric order, except folders already visited in the same session, which reopen their session last-viewed image — RAM-only memory).
- [x] Wave 4 — Fullscreen mode + zoom in/out and fit width/fit height modes. Fullscreen behavior (per user decision 2026-10-29): default OFF at launch — window opens normal or maximized at the user's own placement/size; fullscreen OFF shows UI controls (UI layout details deferred to later definition by the user) with the image taking almost all of the central space; fullscreen ON hides the window header and ALL controls, showing only the image.

- [x] Wave 6 — Fast "Open with..." menu (system-registered programs for the current file type).
- [x] Wave 7 — Distribution and packaging: zip-style portable installer, config file, default-viewer registration helper/guidance. Carries the MVP checkpoint: MVP = end of Wave 7 (full v1) per user decision 2026-10-29; only THIS wave may write the first changelog entry (waves 1–6 must not touch CHANGELOG.md).

Each wave file must mark explicitly: requirements source sections, expected deliverables, verification expectations, and — where the brief defers a decision (WIC binding, keybindings, zoom steps, module layout, helper mechanism, config format) — that the decision belongs to that wave's analysis step.
