# 20261029-todo-1 — Project Brief (Rust Image Scroller)

## Task Origin

- Chat request (user, 2026-10-29): "Help me write down the project brief" for the project idea explained in chat.
- Idea: a Rust Windows app recreating the old Windows "gallery" style viewer: open an image and scroll through sibling images (left/right arrows / UI buttons) and sibling folders (up/down arrows / UI buttons) under the same parent folder, unlike modern Windows viewers which lack this.
- Requirements were gathered and confirmed via Q&A; full captured decisions are in `.kilo/plans/20261029-project-brief.md` (Pre-analysis section). Key answers:
  - GUI stack: egui/eframe.
  - Image decoding: system codecs (WIC) — supports any format registered in the system.
  - Windows target: Windows 10/11, x64 + x86.
  - Vertical scroll rule: always open the folder's first image when the same filename is missing; keep a per-session "last viewed image per folder" memory (destroyed on app close).
  - "Fast Open with..." menu: system-registered programs for the current file type.
  - Sort order: alphanumeric for folders and files; add note for future settings so the user can modify it.
  - Distribution: zip-style installer (choose destination folder, unzip app + config), plus guidance/helper for registering the app as default image viewer.
