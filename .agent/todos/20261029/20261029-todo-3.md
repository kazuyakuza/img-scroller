# Wave 1 — Project Skeleton and Open Image

Wave 1 boots the greenfield application: a Cargo project with an egui/eframe window that can open an image (from a CLI argument or an in-app open dialog), decode it via the Windows system codec layer (WIC), and display it in a regular resizable viewer window.

- [ ] If launched with an image-path CLI argument, load that image; otherwise the user opens an image via an in-app open dialog (native Windows open dialog approach decided in this wave's architector step).
