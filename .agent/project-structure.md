# Project Structure

# Files in src/

- app.rs - eframe application shell: open-flow state, the empty-state centered Open button, the navigation-context gate for the floating pill (image open or browsed empty folder), four-direction arrow-key navigation and the shared navigate seam, in-session folder/sibling-folder listings plus last-viewed memory and empty-folder-browse state, the session pan offset (reset on open and restore-to-fit), window-title constant; the shared central-surface paint seam and the fullscreen/zoom/fit/pan state routed through the child modules below
- app_display.rs - central image display: texture lifecycle wrapper (one upload per decode), fit-scaled paint repositioned by the clamped pan offset, pending-upload flag
- folder_listing.rs - current-folder image listing for horizontal navigation: one non-recursive parent-folder read, 17-extension image whitelist, ±1 neighbor stepping with list-edge reports, plus first_listed_image (the vertical first-image priority probe); sorts through the shared EntryNameOrder system-order seam
- image_loading.rs - open-image seam: load_image entry, DecodedImage payload shape, failure classification, unsupported-file message constant
- main.rs - entry point: CLI image-path intake, module registration, the viewer window options (resizable, always maximized at launch, title from `app::APP_WINDOW_TITLE` -- relocated here from `app.rs` in Wave 5), starts the eframe native app with the console hidden in release builds
- last_viewed_images.rs - session RAM map of the last displayed image per visited folder: created empty with the app, updated at every open-success, read for the visited-folder target priority, destroyed with the app (no persistence)
- name_collation.rs - entry-name ordering for both listings: the EntryNameOrder comparator-as-data seam resolving through the platform facade to the system name order, plus the pure fallback collation (lowercase form first, exact-character tie-break) used on system failures and in container/stub builds; inline unit tests
- pan.rs - pure Wave-5 pan math: per-axis overflow, the symmetric [-limit,+limit] clamp and at-edge predicates, the 0.125-of-available-axis pan step, and the arrow pan-or-navigate decision (an axis that fits entirely navigates directly; an overflowing axis pans on every press including auto-repeats until its edge, where only a distinct non-repeat press navigates); the reset policy lives in the app and the paint consumes it in app_display.rs; tests in the `pan/` child module
- sibling_folder_listing.rs - sibling-folder listing for vertical navigation: one non-recursive read of the current folder's parent, immediate child directories only (current folder excluded; symlinked entries unlisted), EntryNameOrder system-order sort with the anchor position read against the same stored order, ±1 folder stepping with scope-edge reports
- scaling.rs - pure fit-scaling math: largest uniform factor for the available area, plus the Wave-4.1 one-shot fit-width/fit-height factors (axis-ratio over the whole-image fit, clamped into the symmetric zoom bounds; no egui painting)
- zoom.rs - pure zoom math: the ×1.25 step clamped to the SYMMETRIC [1/8, 8] bounds (floor = 1.0/ceiling; the ÷8 floor lets zoom-out pass fit), at-bound predicates, the restore-to-fit constant, and the fit-size × factor draw-size composition (with its inline unit tests)

# Folders in src/

- app/ - child modules of the application shell: arrow_direction.rs (painted-arrow control types for the floating pill), button_hint.rs (the pill-button hotkey captions + hover-tooltip strings keyed by button, plus the shared top-aligned vertical button-column wrapper), floating_controls.rs (centered floating bottom pill: message line + the 10-button row of painted vector arrows, the fullscreen square, the zoom [+][−][restore-fit] and fit-width/fit-height groups), folder_navigation.rs (shared navigate seam: the four directions' ±1 neighbor resolution on both axes, the vertical target-image priority, and empty-folder mode), empty_folder_view.rs (the empty-folder browsing message), empty_state_view.rs (the fresh empty-state centered Open button), esc_close_confirm.rs (the fullscreen-OFF ESC double-press close affordance: the centered 2-second "Press ESC again to close" popup constants, state helpers (arm/disarm/expiry) and render, plus the pure non-repeat press filter and the arm/idle/close branch decision), fullscreen.rs (session fullscreen flag: F11/button toggle action sending the viewport command, the chrome visibility gate, the fullscreen surface), fullscreen_button.rs (the pill's always-enabled painted-square fullscreen button), keyboard_intake.rs (the one per-frame keyboard intake: F11, ESC-exit-fullscreen, the ESC-close arm/close branch plus per-frame popup expiry, zoom I/O/0 with the strict shift aliases, one-shot fit W/H, the four pan-or-navigate arrows), pan.rs (the keyboard-only pan-or-navigate controller: maps each arrow press's direction to its axis/sign, routes through crate::pan's pure decision between a pan step and edge navigation, gates at-edge navigation on a distinct non-repeat press, and owns the pan-offset reset-on-open/restore plus the re-clamped writes to app state; math delegated to the top-level crate::pan), pill_style.rs (the shared pill-styling primitives: glyph/caption color palette, the 1-point black outline constants, the outlined shape builders, and the outlined hotkey-caption paint), zoom.rs (zoom app seam: symmetric-bound factor steps with silent clamping, the I/O chord functions delegating the shift-gated aliases to zoom_alias.rs, the at-bound/off-fit dimming predicates, and the one-shot set_zoom_to_fit_width/fit_height seams), zoom_alias.rs (the strict shift-gated zoom-alias layer extracted from zoom.rs in Wave 4.2 A-Task 3: the accept-set spans both the egui key resolutions and the typed Event::Text characters, every member individually Shift-gated so plain keys stay inert for every keyboard layout), zoom_button.rs (the three zoom pill buttons with at-bound dimming), fit_button.rs (the two one-shot fit pill buttons gated on an open image; renamed from fit_mode_button in Wave 4.1 Task 7), central_surface.rs (the single ImagePainting paint seam shared by chrome and fullscreen), plus the test modules tests.rs, floating_controls_tests.rs, folder_navigation_tests.rs, folder_navigation_continuation_tests.rs, last_viewed_tests.rs, fullscreen_tests.rs, zoom_alias_tests.rs, zoom_tests.rs, fit_one_shot_tests.rs, pill_style_tests.rs, button_hint_tests.rs, esc_close_confirm_tests.rs, esc_close_expiry_tests.rs, pan_tests.rs
- folder_listing/ - child module: tests.rs (listing/collation/neighbor unit tests), collation_tests.rs (injected-order seam tests for Japanese/ASCII fallback ordering)
- pan/ - child module: pan_tests.rs (per-axis overflow, the symmetric clamp, pan-step sign/size, the at-edge decision, repeat absorption and pinned-constant unit tests)
- sibling_folder_listing/ - child modules: tests.rs (listing/collation/self-exclusion/non-recursive/empty-scope unit tests), neighbor_tests.rs (neighbor-stepping unit tests + the symlink policy tests, reusing the sibling tests module's TempScope fixture), collation_tests.rs (injected-order seam tests proving vertical sort and anchor position use the same comparator)
- platform/ - OS-bound facade for the native open dialog, WIC decode and the system entry-name order: mod.rs (facade re-exports), windows.rs (Windows implementation), windows_collation.rs (user-default-locale CompareStringEx with NORM_IGNORECASE; failures surface as None so windows.rs falls back to the pure collation), stub.rs (non-Windows fallback)
